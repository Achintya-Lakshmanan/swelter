# awesome-design-md

Source: https://github.com/VoltAgent/awesome-design-md (MIT, see LICENSE). Each file in `designs/` is one site's
DESIGN.md: colors, typography, spacing, components and do's and don'ts, written for coding agents.

## How to use

1. List `designs/` and pick the 1–3 files closest to the brief (for dark data-heavy map tools: `uber.md`,
   `linear.app.md`, `vercel.md`, `posthog.md`, `theverge.md`, `spacex.md`).
2. Read the chosen file in full before writing any CSS.
3. Adopt its tokens and component rules for the page; keep the project's own content and data. Borrow a design
   language, never another company's logo, name or brand assets.
4. Say which DESIGN.md you followed and what you adapted.
